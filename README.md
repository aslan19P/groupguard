# GroupGuard

Универсальный Telegram-бот для модерации одной супергруппы на один экземпляр.
GroupGuard автоматически удаляет точные повторы объявлений с телефоном, выдаёт мут
на семь дней и отправляет неоднозначные случаи в синхронизированные личные панели
владельцев. Внешний AI, OCR, домен и webhook не нужны.

## Что умеет v1

- распознаёт номера `+998`, `998…`, локальные девятизначные номера, пробелы, скобки
  и дефисы, а также Telegram phone entities и `tel:`-ссылки;
- считает точным дублем только совпадение автора, календарного дня настроенного
  часового пояса, нормализованного текста и хотя бы одного номера;
- полностью сбрасывает сравнение при наступлении нового календарного дня: вчерашние
  объявления не создают ни санкцию, ни случай для ручной проверки;
- сначала ограничивает автора на семь дней, затем удаляет повтор;
- фотографии и похожие объявления отправляет владельцам без автоматической санкции;
- синхронизирует решение карточки между личными чатами владельцев;
- последовательно обрабатывает одновременные сообщения одного пользователя и
  защищает записи атомарными PostgreSQL-upsert и транзакционными блокировками;
- хранит владельцев, белый список, санкции, usernames и агрегированную статистику в
  PostgreSQL;
- очищает временные отпечатки через 48 часов, открытые случаи через 14 дней и
  подробный аудит через 30 дней.

## Быстрый запуск

1. Создайте бота через `@BotFather`.
2. Скопируйте `.env.example` в `.env` и замените все заглушки. Два секрета можно
   сгенерировать командой:

   ```bash
   python3 -c "import secrets; print(secrets.token_urlsafe(32))"
   ```

   `TIMEZONE` определяет календарный день для поиска дублей и часовой пояс всех дат
   в интерфейсе. По умолчанию используется `Asia/Tashkent`. Данные в PostgreSQL при
   этом безопасно хранятся в UTC.

3. Запустите сервисы:

   ```bash
   docker compose up --build -d
   docker compose logs -f bot
   ```

4. Один раз откройте ссылку:

   ```text
   https://t.me/<bot_username>?start=bootstrap_<BOOTSTRAP_TOKEN>
   ```

5. В `@BotFather` откройте `/setprivacy`, выберите бота и нажмите `Disable`.
   Проверить настройку можно через `/mybots` → бот → `Bot Settings` →
   `Group Privacy`: режим должен быть выключен.
6. Добавьте бота администратором супергруппы и разрешите ему удалять сообщения и
   блокировать пользователей. Владелец, который подключает группу, тоже должен быть
   её администратором.
7. В личной панели нажмите «Подключить группу», откройте клавиатуру кнопкой из
   четырёх квадратов рядом со строкой ввода и выберите «Выбрать группу».

Bootstrap-ссылка перестаёт работать после создания первого владельца. Остальные
владельцы добавляются из панели по `@username`; приглашение действует 24 часа и
используется один раз.

## Команды владельца

- `/start` — активация приглашения или открытие панели;
- `/menu` — открыть или обновить панель;
- `/help` — краткая инструкция и решения частых проблем прямо в Telegram.

Панель содержит очередь проверки, активные ограничения, белый список, владельцев,
поиск пользователя, историю и переключатель мгновенных уведомлений. Критические
ошибки и изменения списка владельцев отправляются независимо от переключателя.
Уведомление об ошибке объясняет её категорию и этап, показывает безопасный контекст
обновления и код инцидента. Полный traceback остаётся только в журнале контейнера.

## Как пользоваться панелью

### Белый список

Владельцы защищены автоматически, добавлять их в белый список не требуется. Чтобы
защитить другого участника:

1. участник должен хотя бы один раз отправить сообщение в подключённой группе;
2. в панели нажмите «Найти человека»;
3. отправьте известный `@username` или числовой Telegram ID;
4. в найденной карточке нажмите «В белый список».

Кнопка «Белый список» открывает перечень уже защищённых людей и позволяет удалить
их из него. Telegram Bot API не разрешает искать произвольный аккаунт только по
username, поэтому сначала бот должен увидеть пользователя в группе.

### Владельцы

В разделе «Владельцы» нажмите «Добавить владельца» и отправьте его `@username`.
GroupGuard создаст одноразовую ссылку на 24 часа. Новый владелец должен открыть её
с нужного Telegram-аккаунта. После активации бот хранит постоянный `user_id`, поэтому
смена username не лишит человека доступа. Последнего владельца удалить нельзя.

### Ограниченные пользователи

Во всех разделах панели пользователь показывается одинаково: имя, username и
постоянный Telegram ID. Формат используется в очереди «На проверке», карточках
случаев, ограничениях, белом списке, владельцах, поиске и истории действий. Имя в
тексте и отдельная кнопка `👤` открывают профиль:

- при наличии username используется публичная ссылка `https://t.me/username`;
- без username имя показывается обычным текстом с пометкой «username отсутствует»;
  кнопка открывает внутреннюю карточку GroupGuard. Telegram может запрещать прямые
  `tg://user`-ссылки настройками приватности пользователя, поэтому бот их не создаёт.

Причины и результаты модерации выводятся понятными русскими подписями. Кнопки снятия
мута, удаления и других действий находятся отдельно от кнопки профиля, чтобы их
нельзя было перепутать с переходом к пользователю.

### Автоматическая модерация

Точный дубль определяется только при одновременном выполнении условий:

- тот же автор;
- тот же календарный день в часовом поясе из `TIMEZONE`;
- тот же нормализованный текст;
- совпал хотя бы один телефонный номер.

В таком случае бот сначала ограничивает автора на семь дней, затем удаляет повтор.
Первое сообщение остаётся. Владельцы и белый список полностью исключены из
автоматических санкций.

Карточка случая содержит ссылку на проверяемое сообщение и, если найдено
совпадение, отдельную ссылку на самое первое совпавшее сообщение.

Похожий текст, один номер у разных аккаунтов, повторный файл, визуально похожая
фотография и подозрительное редактирование попадают в «На проверке». До решения
владельца такие сообщения автоматически не удаляются.

## Частые проблемы

### Бот пишет, что группа не подключена

Старая карточка панели не обновляется сама. Отправьте `/menu`. Если группа всё ещё
не указана, повторите подключение и убедитесь, что владелец и бот являются
администраторами.

### Не видно кнопки «Выбрать группу»

Telegram может свернуть служебную клавиатуру. Нажмите значок из четырёх квадратов
рядом со строкой ввода. На появившейся клавиатуре будет кнопка «Выбрать группу».

### Бот не видит обычные сообщения

Отключите Privacy Mode через `@BotFather`: `/setprivacy` → нужный бот → `Disable`.
Если Telegram продолжает показывать «не имеет доступа к сообщениям», удалите бота
из группы и снова добавьте его администратором.

### Поиск не находит пользователя

Попросите пользователя отправить любое сообщение в подключённой группе, затем
повторите поиск по актуальному `@username`. Также можно искать по Telegram ID, если
он известен.

### Одноразовая ссылка больше не открывается

Bootstrap-ссылка действует только до создания первого владельца. Приглашение нового
владельца действует 24 часа и также используется один раз. Уже активированный
владелец открывает панель командой `/menu`, повторная ссылка ему не нужна.

## Обновление и обслуживание

```bash
git pull
docker compose up --build -d
docker compose ps
docker compose logs --tail=100 bot
```

Контейнеры настроены с `restart: unless-stopped`, поэтому после перезагрузки сервера
бот и PostgreSQL запускаются автоматически. Для остановки используйте
`docker compose down`; volume базы данных при этом сохраняется.

## Разработка и проверка

```bash
python3.11 -m venv .venv
source .venv/bin/activate
make install
make check
```

Для интеграционных тестов сначала примените миграцию к отдельной тестовой базе и
передайте её адрес:

```bash
DATABASE_URL=postgresql+psycopg://groupguard:groupguard@127.0.0.1:55432/groupguard_test \
  alembic upgrade head
TEST_DATABASE_URL=postgresql+psycopg://groupguard:groupguard@127.0.0.1:55432/groupguard_test \
  pytest
```

PostgreSQL из Compose доступен только через loopback-порт `55432`; извне хоста он
не публикуется. В контейнере бот использует адрес сервиса `postgres:5432`.

## Данные и приватность

Сырые телефонные номера не сохраняются: для связей используется HMAC-SHA256, а в
карточках остаются только маски. Полный текст сообщений не журналируется; временно
хранится только короткий фрагмент. SQL-параметры скрыты даже в аварийных логах.
Локальная копия фотографии существует только во время вычисления perceptual hash;
долгосрочно хранится Telegram `file_id`.

Для резервного копирования достаточно сохранять Docker volume PostgreSQL. Смена
`PHONE_HMAC_SECRET` делает старые телефонные отпечатки несопоставимыми, поэтому её
лучше выполнять после истечения 48-часового окна.
