# GroupGuard

Универсальный Telegram-бот для модерации одной супергруппы на один экземпляр.
GroupGuard автоматически удаляет точные повторы объявлений с телефоном, выдаёт мут
на семь дней и отправляет неоднозначные случаи в синхронизированные личные панели
владельцев. Внешний AI, OCR, домен и webhook не нужны.

## Что умеет v1

- распознаёт номера `+998`, `998…`, локальные девятизначные номера, пробелы, скобки
  и дефисы, а также Telegram phone entities и `tel:`-ссылки;
- считает точным дублем только совпадение автора, календарного дня Ташкента,
  нормализованного текста и хотя бы одного номера;
- сначала ограничивает автора на семь дней, затем удаляет повтор;
- фотографии и похожие объявления отправляет владельцам без автоматической санкции;
- синхронизирует решение карточки между личными чатами владельцев;
- хранит владельцев, белый список, санкции, usernames и агрегированную статистику в
  PostgreSQL;
- очищает временные отпечатки через 48 часов, открытые случаи через 14 дней и
  подробный аудит через 30 дней.

## Первый запуск

1. Создайте бота через `@BotFather`.
2. Скопируйте `.env.example` в `.env` и замените все заглушки. Два секрета можно
   сгенерировать командой:

   ```bash
   python3 -c "import secrets; print(secrets.token_urlsafe(32))"
   ```

3. Запустите сервисы:

   ```bash
   docker compose up --build -d
   docker compose logs -f bot
   ```

4. Один раз откройте ссылку:

   ```text
   https://t.me/<bot_username>?start=bootstrap_<BOOTSTRAP_TOKEN>
   ```

5. В личной панели нажмите «Подключить группу». Перед выбором добавьте бота в
   супергруппу администратором и дайте права удаления сообщений и ограничения
   участников.

Bootstrap-ссылка перестаёт работать после создания первого владельца. Остальные
владельцы добавляются из панели по `@username`; приглашение действует 24 часа и
используется один раз.

## Команды владельца

- `/start` — активация приглашения или открытие панели;
- `/menu` — открыть панель повторно.

Панель содержит очередь проверки, активные ограничения, белый список, владельцев,
поиск пользователя, историю и переключатель мгновенных уведомлений. Критические
ошибки и изменения списка владельцев отправляются независимо от переключателя.

## Разработка и проверка

```bash
python3.11 -m venv .venv
source .venv/bin/activate
make install
make check
```

Для интеграционных тестов сначала примените миграцию к отдельной тестовой базе и
передайте её адрес:

```bash
DATABASE_URL=postgresql+psycopg://groupguard:groupguard@127.0.0.1:55432/groupguard_test \
  alembic upgrade head
TEST_DATABASE_URL=postgresql+psycopg://groupguard:groupguard@127.0.0.1:55432/groupguard_test \
  pytest
```

PostgreSQL из Compose доступен только через loopback-порт `55432`; извне хоста он
не публикуется. В контейнере бот использует адрес сервиса `postgres:5432`.

## Данные и приватность

Сырые телефонные номера не сохраняются: для связей используется HMAC-SHA256, а в
карточках остаются только маски. Полный текст сообщений не журналируется; временно
хранится только короткий фрагмент. SQL-параметры скрыты даже в аварийных логах.
Локальная копия фотографии существует только во время вычисления perceptual hash;
долгосрочно хранится Telegram `file_id`.

Для резервного копирования достаточно сохранять Docker volume PostgreSQL. Смена
`PHONE_HMAC_SECRET` делает старые телефонные отпечатки несопоставимыми, поэтому её
лучше выполнять после истечения 48-часового окна.
